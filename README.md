Crime Analysis – Tableau Project

Prepared By: Ishaan Singh

Project Overview

Analyzed historical crime data using Tableau to develop four interactive dashboards. The project transforms crime data into meaningful visualizations and structured insights to analyze geographical crime distribution, common incident types, time-based patterns, year-over-year trends, arrest outcomes, and incident severity.

Project Components:

1. Crime Analysis Project Guidelines: Assignment brief outlining the project objectives, analysis requirements, dashboard requirements, and expected outcomes.

2. Crime Analysis Project Report: Analysis report containing the project overview, key dashboard insights, and conclusion derived from the Tableau analysis.
   
3. Crime Analysis Dataset: Dataset used to develop the visualizations and perform the crime analysis.
   
4. Tableau Public Workbook and Dashboards: Tableau workbook containing four interactive dashboards—Overall Crime Statistics Dashboard, Time Period Analysis Dashboard, Trend Analysis Dashboard, and Comparative Analysis Dashboard.
   
5. Dashboard Screenshots: Screenshots of all four Tableau dashboards.
   
Tools & Techniques Used:

Tableau | Data Visualization | Data Analysis | Bar Charts | Line Charts | Maps | Tables | Pie Charts | Filters | Trend Analysis | Data Storytelling
